# 右键菜单功能说明

雪莉支持通过**右键点击**打开功能菜单，快速切换各种设置。

## 如何打开

在雪莉窗口上**点击右键**，即可打开功能菜单。

## 菜单功能

### 🎭 Expression（表情）
快速切换雪莉的表情：
- Normal（正常）
- Happy（开心）
- Sad（难过）
- Angry（生气）
- Love（爱心）
- Blush（害羞）
- Daze（发呆）

### 🌐 Language（语言）**[NEW]**
切换语音语言（自动翻译）：
- 🇨🇳 **中文** - 使用中文语音播放
- 🇯🇵 **日本語** - 切换到日文语音，**中文输入会自动翻译成日文**
- 🇺🇸 **English** - 切换到英文语音

**自动翻译开关**：控制是否启用自动翻译功能
- 开启：中文输入会自动翻译成目标语言
- 关闭：直接播放输入的文本

### 🎙️ TTS 设置
语音合成相关设置：
- **启用语音** - 开启/关闭语音播放
- **选择引擎** - 切换 TTS 引擎（Edge / GPT-SoVITS / Local）
- **测试语音** - 快速测试不同语音
- **口型同步** - 开启/关闭嘴唇同步动画

### 其他功能
- **去水印** - 移除 Live2D 模型水印
- **🖱️ 鼠标穿透** - 点击穿透窗口（不影响操作其他软件）
- **👤 大头模式** - 放大头部显示
- **👁️ 视线跟随** - 雪莉的眼睛跟随鼠标移动

---

## 使用示例

### 切换到日文模式

1. 右键点击雪莉
2. 选择 `🌐 语言`
3. 点击 `🇯🇵 日本語`
4. 雪莉会用日文说「こんにちは、シェリーです」

### 中文自动翻译成日文

1. 切换到日文模式后
2. 确保 `🔄 自动翻译` 已开启
3. 发送中文消息："你好，今天过得怎么样？"
4. 雪莉会用日文说出翻译后的内容
